# Rder - Driver's License Information Platform

A web platform providing comprehensive information about driver's licenses, renewals, and requirements.

## Features
- Information about driver's license requirements
- License renewal guidance
- Contact and registration system
- Responsive design for all devices

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Supabase (Database)
- Bootstrap

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
3. For development, use a local server
